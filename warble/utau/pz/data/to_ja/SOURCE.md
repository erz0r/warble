# foreign-lyrics-on-japanese-banks templates

copied unchanged from openutau (MIT license, Copyright (c) 2014 StAkira and contributors,
https://github.com/stakira/OpenUtau), `OpenUtau.Plugin.Builtin/Data/`. each is the yaml openutau writes into its
plugin folder on first use (the `YamlTemplate` resource of the phonemizer); warble reads them in place of that
folder.

- en2ja.template.yaml: plugin-folder `en2ja.yaml` (ENtoJAPhonemizer, entoja.py)
- fil2ja.template.yaml: plugin-folder `fil2ja.yaml` (FILtoJAPhonemizer, filtoja.py)
