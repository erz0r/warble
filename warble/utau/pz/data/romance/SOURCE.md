# romance/slavic syllable based phonemizer templates

copied unchanged from openutau (MIT license, Copyright (c) 2014 StAkira and contributors,
https://github.com/stakira/OpenUtau), `OpenUtau.Plugin.Builtin/Data/`. each is the yaml openutau writes into
its plugin folder on first use (the `YamlTemplate` resource of the phonemizer, embedded via `Resources.resx`);
warble reads them in place of that folder.

- de_vccv.template.yaml: plugin-folder `de_vccv.yaml` (GermanVCCVPhonemizer)
- njokis.template.yaml: plugin-folder `njokis_vccv.yaml` (SpanishVCCVPhonemizer)
